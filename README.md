# 罗湖通勤租房地铁图

打开 `index.html` 即可使用。2026-08-14 已补齐国贸、老街、大剧院、科学馆、红岭、晒布、通新岭、翠竹、湖贝、燕南、东门共 11 个一级站点，并保留黄贝岭、罗湖两个扩展/终点站。高德住宅候选统一满足“距站点 1 公里内、距罗湖口岸 4 公里内”；逐一查询乐有家后，页面展示 1,355 条唯一一居链接，覆盖 146 个有房小区。

## 已实现

- 11 个一级站点全部接入，并额外保留黄贝岭与罗湖；站点筛选显示房源数量和到罗湖地铁估算
- 顶部地图已替换为用户标注的高德 4 公里红色半径截图；房源数据仍按各目标站 500 米内采集
- 按站点、小区名称、最高租金筛选
- 用双端滑块筛选 2400–5000 元月租，并支持租金升降序
- 1,355 条房源原链接跳转
- 图片式房源卡片与看房详情层；当前接入 21 套房源、28 张乐有家真实图片，其中 2 套可在详情中浏览多图
- 收藏、只看收藏、按个人评分排序
- 图片状态支持全部、本站相册、有图（≥2 张）、无图（≤1 张）和待核；当前 338 条已核验为原站有图、98 条为无图，其余保留待核状态
- 按站点、小区筛选并查看全部命中房源；小区卡片同时显示高德实际步行和预计到罗湖总通勤
- 硬装 / 软装 / 采光三项五星评分与自动保存的看房笔记
- 小红书港硕、港深通勤和重点小区检索入口
- 桌面与手机响应式布局

收藏、评分和笔记保存在浏览器 `localStorage`，刷新页面后仍会保留，但不会自动同步到其他电脑。没有抓到封面的房源会明确标为“待补图”，不会使用其他小区图片替代；进入详情后可一键打开乐有家完整相册。大量低价房源只提供视频封面、默认图或无法稳定返回原图，因此图片覆盖率不等于房源有效率。

## 关于“实时”

当前是可交互快照，不是实时抓取。要变成真正实时版本，需要增加一个定时采集层：刷新乐有家页面、按链接去重、输出新的 `data.js`，然后自动部署。乐有家没有在本任务中提供公开 API，因此实时采集需考虑登录状态、页面结构变化和访问频率。

## 数据边界

- 线路是比较站点关系的示意图，不代表精确地理坐标。
- 乐有家列表未提供每套房的可靠经纬度，因此没有伪造地图定位。
- 小红书标题命中不等于口碑已核实；房源广告、转租和真实长期居住体验需要分开阅读。

## 已核验的一篇港硕看房记录

笔记《26港硕｜罗湖10+热门小区暴走看房详细分享》的公开首屏显示：作者为 8 月开学在罗湖口岸附近两天集中看房，最终租在“万科里”。作者的个人判断是，罗湖口岸步行约 10 分钟内的小区多数装修较旧；若偏好更新、更年轻的装修，往往需要退到国贸附近，再以步行加地铁通勤罗湖约 15–20 分钟。作者提到 160 公寓离罗湖地铁站约 7–8 分钟、装修较新，但认为其大堂偏小、层高较低；笔记当时的一居人均价约 4k 以下。以上是单篇笔记的个人体验和当时库存快照，不应直接当作普遍评价或当前报价。
